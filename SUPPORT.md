# Support

Core Code is a public pre-alpha project. Community support is best-effort and
there is no response-time or compatibility SLA.

## Choose the right channel

| Need | Channel |
| --- | --- |
| Usage question, setup help, or design discussion | [GitHub Discussions](https://github.com/Plantcore-AI/core/discussions) |
| Reproducible bug | [Bug report](https://github.com/Plantcore-AI/core/issues/new?template=bug_report.yml) |
| Focused feature proposal | [Feature request](https://github.com/Plantcore-AI/core/issues/new?template=feature_request.yml) |
| Ongoing module responsibility | [Ownership claim](https://github.com/Plantcore-AI/core/issues/new?template=ownership_claim.yml) |
| Suspected vulnerability | Private [Report a vulnerability](https://github.com/Plantcore-AI/core/security/advisories/new) flow |
| Conduct concern | Private route in the [Code of Conduct](CODE_OF_CONDUCT.md) |

Search existing issues and Discussions before opening a new thread. Please use a
minimal synthetic reproduction and include the Core Code version, OS and
architecture, terminal, provider adapter, model identifier, expected behavior,
and observed behavior. Never attach credentials, private session records,
customer data, or proprietary source.

## Supported versions

Until a stable release exists, only the latest public release and current `main`
branch receive fixes. Older pre-alpha releases may be superseded without a patch
release. Supported platforms are documented in the
[installation guide](docs/getting-started/installation.md).

## What support does not include

The project cannot guarantee provider availability, model entitlement, account
funding, third-party API behavior, or recovery of secrets committed to another
repository. Public support channels are not a substitute for an incident-response
or commercial support agreement.

Security reports and conduct reports must stay out of public support channels.
