# Support

Iteron is a public pre-alpha project. Community support is best-effort and
there is no response-time or compatibility SLA.

## Choose the right channel

| Need | Channel |
| --- | --- |
| Usage question, setup help, or design discussion | [GitHub Discussions](https://github.com/Plantcore-AI/Iteron/discussions) |
| Reproducible bug | [Bug report](https://github.com/Plantcore-AI/Iteron/issues/new?template=bug_report.yml) |
| Focused feature proposal | [Feature request](https://github.com/Plantcore-AI/Iteron/issues/new?template=feature_request.yml) |
| Ongoing module responsibility | [Ownership claim](https://github.com/Plantcore-AI/Iteron/issues/new?template=ownership_claim.yml) |
| Suspected vulnerability | Private [Report a vulnerability](https://github.com/Plantcore-AI/Iteron/security/advisories/new) flow |
| Conduct concern | Private route in the [Code of Conduct](CODE_OF_CONDUCT.md) |

Search existing issues and Discussions before opening a new thread. Please use a
minimal synthetic reproduction and include the Iteron version, OS and
architecture, terminal, provider adapter, model identifier, expected behavior,
and observed behavior. Never attach credentials, private session records,
customer data, or proprietary source.

## Supported versions

Until an accepted release exists, only the current `main` branch receives
fixes. Source snapshots may be superseded without a patch release. Supported
platforms and the proposed binary release matrix are documented in the
[installation guide](docs/getting-started/installation.md).

## What support does not include

The project cannot guarantee provider availability, model entitlement, account
funding, third-party API behavior, or recovery of secrets committed to another
repository. Public support channels are not a substitute for an incident-response
or commercial support agreement.

Security reports and conduct reports must stay out of public support channels.
