# Support

Core Code is a public pre-alpha project. Community support is best-effort; there
is no response-time, compatibility, or commercial support SLA.

| Need | Channel |
| --- | --- |
| Setup question or design discussion | [GitHub Discussions](https://github.com/Plantcore-AI/core/discussions) |
| Reproducible bug | [Bug report](https://github.com/Plantcore-AI/core/issues/new?template=bug_report.yml) |
| Focused feature proposal | [Feature request](https://github.com/Plantcore-AI/core/issues/new?template=feature_request.yml) |
| Ongoing module responsibility | [Ownership claim](https://github.com/Plantcore-AI/core/issues/new?template=ownership_claim.yml) |
| Suspected vulnerability | Private [security advisory](https://github.com/Plantcore-AI/core/security/advisories/new) |

Search first. Use a minimal synthetic repository and include version, OS and
architecture, terminal, provider adapter, model id, expected behavior, and
observed behavior. Provider billing, account funding, and entitlement questions
belong with the provider.

Never publish credentials, private run records, customer data, or proprietary
source. Security and conduct reports must stay out of public support channels.

The canonical policy is
[SUPPORT.md](https://github.com/Plantcore-AI/core/blob/main/SUPPORT.md).
