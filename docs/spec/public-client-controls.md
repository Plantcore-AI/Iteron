
### Activity Center V1

`activity_center_v1` wraps strict `ActivityControlV1` List, Inspect or Stop with both the current authenticated `thread_id` and selected `run_id`. Read-only negotiated observers can List/Inspect; Stop requires compatible operator authority. Targets are actual Process job IDs, durable Agent IDs (Stop additionally requires the observed epoch), session Workflow run IDs, MCP actor names, or host verifier task IDs. Activity display labels are not control handles. Eight detached owner operations bound work while the parent continues polling. Stop replies distinguish acceptance from an observed terminal.

`/activity` reads those same owners; `/activity attach|stop process|agent|workflow|mcp|verifier ID` selects a typed handle. Agent stop needs INCARNATION TURN. Verifier IDs bind the real physical run and committed Verify EffectIntent sequence, remain stable when verified effects are reopened, and carry a private cancellation signal for that verifier alone. Pending/unknown restored effects require reconciliation and are never resurrected. A restored EffectDone does not prove a passed check. Attach returns bounded scrubbed oracle feedback, explicitly not a full process log. Persistent controller and verified verifier records retain state; process/MCP/session-supervisor entries report the captured live owners and make no restart-liveness assertion.


### Plugin Management V1

`plugin_management_v1` wraps strict `PluginControlV1` bound to authenticated thread and selected run. List/Inspect are read-only; SetEnabled, SetPrecedence, Rollback and Install require compatible operator control. List pages configuration, actual bootstrap conflicts/refusals, current verified materialization and host-prepared receipts (default16, max32). Inspect pages the package's actual bound surfaces. Install accepts only an opaque host-prepared receipt ID; it cannot accept a package path, publisher key, actor or capability grant.

`/plugins list OFFSET`, `/plugins inspect ID OFFSET`, `/plugins disable|enable ID`, `/plugins priority ID RANK`, `/plugins rollback ID` and `/plugins install RECEIPT` use this same owner. Disable/rollback revoke the loaded generation's future actual dispatch before filesystem work. Already executing work retains its actual owner status; no immediate termination is inferred. Enable/install/precedence remain pending the next verified bootstrap, and enable never unmasks the current generation. Persistent success requires signed copied identity and real file/namespace barriers; failure reports unconfirmed selection while retaining local revocation. Current loaded identities remain distinct from desired configuration/rollback targets. Package-level cost totals remain unavailable; existing tool/provider ledgers retain their actual attribution.

Eight bounded detached controls hold the real resident generation lease through owner effects. Adoption waits on the exclusive lease with a finite deadline, and stale control scope is rejected before side effects. Plugin-free sessions allocate no mask/management semaphore and make no management I/O.
